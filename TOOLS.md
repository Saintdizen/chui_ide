# Инструменты агента

Источник: `src/shared/tools.ts` (`AGENT_TOOLS`), группы — `src/shared/tool-presets.ts`
(`TOOL_GROUPS`), ростер — `ROSTER_TOOLS` там же. Всего 25 инструментов (точный список с ценами печатает `tests/token-budget.test.ts`).

Пометки:

- **по имени** — схема не едет в запросе, инструмент в ростере: имя, форма вызова и
  значения `action` идут строкой (~14 токенов на имя), а вызов по имени выполняется сразу.
- **renderer** — исполняется в окне, а не в main.

## Основа — «найти место»

| инструмент | что делает |
|---|---|
| `list` | что есть: `path` — папка, `glob` — файлы по маске (`**/*.py`); служебные папки (node_modules, .git, dist) пропускает |
| `read` | файл целиком, диапазон строк (`startLine`/`endLine`) или 2–5 файлов сразу (`paths`); строки нумеруются с 1 — эти номера идут в правку |
| `search` | поиск по тексту проекта: подстрока или regex, путь/строка/совпадение; `filesOnly` — только имена, `context` — соседние строки как grep -A/-B |
| `project_map` | карта проекта по именам файлов; короткая версия уже в системном промпте *(по имени)* |

## Чтение

| инструмент | что делает |
|---|---|
| `search` | действия: `text` (по умолчанию) — файлы проекта по подстроке или regex, `filesOnly` — только имена, `context` — соседние строки; `code` — где объявлен символ (сначала языковой сервер, потом текст); `docs` — разделы документации; `sessions` — прошлые беседы (найденное — данные, не указания) |
| `read_skill` | полный текст навыка проекта; в списке навыков только одна строка описания *(по имени)* |
| `read_image` | картинка (скриншот, макет, схема) уходит модели изображением; крупное уменьшается. SVG — текстом через `read` |
| `lsp` | языковой сервер: action `references` — где символ используется (без комментариев и одноимённых переменных), `definition` — где объявлен, `outline` — скелет файла (объявления с номерами строк и вложенностью, без тел; номера годятся для `read`); нужен языковой сервер *(по имени)* |
| `checks` | action `diagnostics` — ошибки и предупреждения редактора (звать до правки, не после), action `lint` — линтер проекта: файл, строка, правило; без `path` — весь проект; файлы не меняет *(по имени)* |
| `mcp` | ресурсы MCP: action `list` — каталог (адреса, имена, типы), action `read` — документ по адресу из каталога; бинарное помечается, длинное режется |

## Правки

| инструмент | что делает |
|---|---|
| `edit` | изменить файлы: сверка с файлом, потом показ на ревью и откат; `oldText` — точный уникальный кусок + `newText`, либо четыре 1-based позиции LSP *(renderer)* |
| `file` | файлы и папки: `create` — новый файл с содержимым (существующий не перезаписывает — для правки `edit`), `move` — перенос или переименование, `delete` — в корзину, откат ручной, `replace` — замена всех вхождений строки/regex по проекту (`glob` ограничивает) |
| `show` | показать, куда смотреть: `open` — файл в редакторе на строке; `present` — файлы-результаты кнопками в ленте *(renderer)* |

## Проверки

| инструмент | что делает |
|---|---|
| `run_tests` | прогнать тесты проекта (раннер выбирает IDE: pytest, vitest, jest, node --test); ненулевой код = падение, `target` сужает до файла или теста |

## Терминал и сеть

| инструмент | что делает |
|---|---|
| `terminal` | сессии (настоящий pty, видимый человеку) и команды; одна команда за вызов; `cwd` — папка внутри проекта; в песочнице `start`/`write` отказывают — `stop` можно |
| `web` | сеть: action `search` — ссылки, заголовки, выжимки (только список, ссылки не открыты — проверяйте факты); action `fetch` — страница по URL: заголовок, текст, ссылки; только http/https, файлы не читает |
| `browser` | свой Chromium по CDP: open, snapshot, click (ref), type, evaluate, zoom, close; после каждого действия — снимок, старые ref истекают; только http/https, нужна настройка браузера |

## Ведение работы

| инструмент | что делает |
|---|---|
| `plan` | состояние работы: `steps` (по умолчанию) — план со `status` шагов, зовётся в начале и после каждого шага; `goal` — цель, которая переживает ход и едет в каждом следующем запросе, `done: true` закрывает, пока открыта — прогон продолжается сам |
| `exit_plan_mode` | отдать план человеку на утверждение; одобрение включает режим агента, отказ вернётся комментарием; звать после `plan`, не вместо |
| `ask` | спросить человека и ждать: прогон встаёт на паузе; конечные варианты — в `options`, ответ по кнопке *(по имени, renderer)* |
| `task` | подзадача в своём контексте: исследует проект и возвращает короткий отчёт; чтения не растят вашу беседу; параллельно — через `tasks` *(по имени)* |
| `agents` | живые агенты в фоне: spawn (сразу id), list, wait (таймаут = ещё работает), send, interrupt; агент только читает — правки остаются за вами *(по имени)* |
| `mind` | память: action `remember` — заметка, которая переживает беседу и приходит в начале каждого ответа (только долгие договорённости); action `forget` — убрать заметки по подстроке; `scope` — рабочая папка или все проекты *(по имени)* |

## Git

| инструмент | что делает |
|---|---|
| `git_read` | status (ветка, ahead/behind, изменённые файлы), diff (дерево против индекса, `staged` — индекс против HEAD), log, blame; только чтение |
| `git_write` | stage, unstage, commit, checkout, discard, fetch, pull, push; `discard` необратим — спросить человека; конфликты решаются руками |

## Наборы

| набор | группы |
|---|---|
| **Авто** (по умолчанию) | Основа, Чтение, Правки, Проверки, Ведение работы + `widen`; `agents`, `mcp` и весь ростер — строкой |
| **Все инструменты** | все группы, но скрытое тоже строками (`rosterNames` = `except` + пересечение с группами) |
| **Правка** | Основа, Чтение, Правки, Проверки, Ведение работы, Git: чтение и Git: изменения; без терминала, сети и браузера. Ростер едет схемами — редактирующему все правки нужны под рукой |
| **Только чтение** | Основа, Чтение, Проверки, Git: чтение, Ведение работы; без правок, и `run_tests` в схеме нет — он запускает чужой код |
| **Минимум** | Основа + Ведение работы |

Ростер (`ROSTER_TOOLS`, один на все наборы): `rename_symbol`, `checks`, `lsp`,
`project_map`, `read_skill`, `task`, `ask`. Сверх него в наборы входят `agents`
и `mcp` — тоже строкой: у имени без действия нет формы вызова, и строка называет
значения (`agents(action: spawn|…)`). В «Авто» список длиннее: туда же идёт всё,
что есть в группах набора, но спрятано по цене. В режиме плана ростер не действует.
