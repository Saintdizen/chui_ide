# TASKS

Три среза, 18 пунктов. Только открытое. Закрыты: LSP и подсказки (33-42), Редактор, Чат.

1. Группы вкладок: перетаскивание вкладки в группу, закрепление группы, сохранение раскладки.
2. Рабочие пространства: сохранить текущую раскладку панелей именем и вернуть одной командой.
3. Плавающая панель и перенос панели в другую сторону из меню.
4. Режим «остался только текст» с выходом по Esc.
5. Заметки человека к файлу и проекту — видны в проводнике, переживают перезапуск.
6. Богатая строка состояния: профиль форматирования, кросс-линии, отключение линз одним щелчком.
7. Тепловая карта несохранённых правок поверх мини-карты.
8. Импорт чужих карт клавиш: VS Code keybindings.json и профиль IDEA.

## 2. Проводник

9. Меню папки и корня: открыть терминал здесь, скопировать путь, найти в этой папке, свернуть потомков.
10. Speed Search: печать поверх дерева фильтрует по префиксу, Enter выбирает.
11. Перетаскивание и переименование через `workspace.updateImports` (объявлен в rpc, не вызывается) — одной отменой.
12. Запоминать фильтр дерева между запусками.
13. Обновление корня (внешний git, смена ветки) не должно сбрасывать раскрытие.
14. Найти все ссылки на файл и показать зависимости из меню файла.

## Правила

1. Перед пунктом — сверка с кодом.
2. Код и вычеркивание пункта — один коммит.
3. Готовое вычеркивается сразу, без пометок.
4. Экономия без числа до и после не считается сделанной.
