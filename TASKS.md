# TASKS

Открытые дела по четырём срезам: Проводник, Редактор, Чат (агент), LSP и подсказки.
Нумерация сквозная и не переиспользуется.

## 1. Проводник

1. **Действие — на любом узле.** Меню файла есть, но у папки нет одним списком
   «Открыть в терминале здесь», «Скопировать путь», «Найти в этой папке»; у корня
   нет «Обновить». У VS Code контекстное меню узла — полный набор, у нас — часть.
2. **Перетаскивание с переносом импортов.** Файл перетаскивается, но правка импортов
   после переноса (у VS Code это расширение, у JetBrains — Move refactoring) не выполняется.
   Пункт: перетащил `.ts` в другую папку — относительные импорты переписаны, undo — одной отменой.
3. **Фильтр дерева переживает переоткрытие.** Исключения проекта читаются
   (README, «Правила проекта и исключения»), но фильтр в дереве не запоминается.
4. **Поиск по проводнику.** Начни печатать поверх дерева — у VS Code это фильтр-набор,
    а Enter уходит в поиск по файлам. У нас такого совмещения нет.
5. **Свёрнутое дерево не схлопывается при обновлении корня.** Состояние раскрытия есть,
    но при обновлении корня дерево схлопывается — у JetBrains и VS Code сохраняется.

### Проверено и найдено готовым — не пункт

- Дерево с ленивой загрузкой, иконки по типу и имени, отметки состояния git на узлах.
- Создание, переименование, удаление, копирование пути, «Открыть с помощью».
- Внешние изменения на диске видны (перечитывание файла, сторож изменений).
- Несколько корней, выход за корень с подтверждением, удалённые файлы через модалку.
- Группировка по типу, «показать скрытые», размеры и число файлов в папке.

## 2. Редактор

6. **Липкая строка области видимости.** `sticky` встречается только в свёртке; у VS Code
    и JetBrains при прокрутке сверху висит текущая функция/класс. Пункт: строка-заголовок
    области, клик — переход к её началу.
7. **Хлебные крошки над файлом.** Их нет (упоминание `breadcrumbs` в дереве — про проводник).
    У VS Code и JetBrains они показывают путь внутри файла и дают прыгать по уровням.
8. **Сворачивание «всё кроме этого».** Из трёх подпунктов свёртки был один — осталось
    «свернуть всё, кроме выбранного» и «свернуть подобранное по выделению».
9. **История правок файла.** Есть undo/redo, но нет Local History поверх сохранений:
    «что было в этом файле час назад», без git. У JetBrains это отдельная панель.
10. **Подсветка вхождений символа под кареткой.** `documentHighlight` у сервера спрашивается,
    но своя подсветка слова на месте в редакторе не включается — VS Code делает оба уровня.
    Пункт: своя подсветка плюс серверная поверх, разные цвета для чтения и записи.
11. **Выделение — по несколько сразу и по столбцу.** Мультикурсор есть, прямоугольного
    выделения (column selection, Alt+drag) нет; у JetBrains и Sublime есть.
12. **Вставка с историей буфера обмена.** Есть очистка вставки (`shared/paste-clean.ts`),
    нет журнала вставок (JetBrains: Ctrl+Shift+V) и «вставить без форматирования»
    отдельной командой.
13. **Шаблоны живого текста.** Есть вставка сниппетов и дополнение, но нет пользовательских
    живых шаблонов с переменными и обходом табуляцией (JetBrains Live Templates).
14. **Postfix-дополнение.** `if.` → `if (…)`, `.var` → переменная. У JetBrains это отдельный
    механизм поверх обычного дополнения; у нас нет.
15. **«Показать невидимое» переключается.** Пробелы, табуляция, переводы строк — команда
    есть местами; нужен переключатель в статусбаре и сохранение выбора.
16. **Сравнение с буфером обмена и с сохранённым.** Сравнение двух файлов и выделений есть;
    «сравнить с буфером» и «сравнить с диском» (у VS Code — в контексте вкладки) нет.

### Проверено и найдено готовым — не пункт

- Правка одного — видна во всех (п.27 прошлого списка), многобуфер.
- Свёртка по уровню, блоки от сервера, свёртка из gutter, сторож свёрнутого.
- Правая колонка-обзор с метками ошибок и правок.
- Поиск с историей, замена в файле и по проекту, регулярные выражения, проверка regex.
- Сравнение двух файлов, с сохранённым в git, структурный поиск и замена.
- Мультикурсор, дополнение пар знаков, умный Enter, комментарии строчные и блочные, обёртка.
- Перемещение и дублирование строк, отступы, форматирование по серверу и по правилам проекта.
- Внутренние ссылки и переход по ним, цвета в файле, инлайн-значения отладчика.
- Настройки редактора: таб/пробелы, ширина, перевод строки, кодировка, автосохранение,
  миникарта, перенос строк, размер шрифта, лигатуры.

## 3. Чат (агент)

17. **Подзадачи вернуть.** Инструмент `task` был снесён коммитом `0fe7cc4` и не восстановлен.
    Нужен заново: отдельная ветка работы со своим контекстом, сводка возвращается
    родителю. У Cursor и Copilot это subagents.
18. **Правила проекта для подпапок.** Читается один набор правил; у Cursor правила свои
    для каждой папки. Пункт: ближайший вверх по дереву файл правил побеждает.
19. **Навыки под юнит.** Движок навыков вернулся (`shared/skills.ts`, `main/ai/skills.ts`),
    но тестов на него нет: поиск навыков, разбор front-matter, ошибки чтения, отсутствие
    кэша как намеренное свойство.
20. **Спилл-файлы большого вывода — под юнит и с уборкой.** `read` и `terminal` отдают через
    файл в `ai-spill/`; нужен тест на порог, на чтение диапазоном и на уборку старых
    (сейчас каталог только растёт).
21. **Журнал шагов переживает перезапуск.** `session.trace` живёт в памяти чата; после
    перезапуска нить разговора есть, а журнала шагов нет. Пункт: журнал сессии — на диске.
22. **Стоимость по модели и по дню.** `usageCost` считается по нити; нет сводки «сколько за
    сегодня» и разбивки по моделям (у Cursor и Copilot это отдельная панель).

### Проверено и найдено готовым — не пункт

- Инструменты (18): `browser`, `checks`, `edit`, `file`, `history`, `list`, `lsp`, `mcp`,
  `mind`, `project_map`, `read`, `read_image`, `run_tests`, `search`, `show`, `skill`,
  `terminal`, `web`.
- Контекст до отправки с ценой, нити разговора со своим местом, стоп гасит инструменты.
- Правка в контексте файла, модель видит то же, что и ты (сверка версий перед отправкой).
- Правила проекта, хуки проекта (до/после вызова), MCP-серверы, навыки (каталог в промпте).
- Пометка сжатия не станет правкой; свёрнутое не свёртывается повторно.
- Модель активная и для коротких подзадач, лимиты, расход токенов по нити.
- Режимы подтверждения инструментов, политика инструментов, пресеты.

## 4. LSP и подсказки

23. **Подсказка параметра — в вызове.** `signatureHelp` подключён, но не показывается, когда
    каретка внутри аргументов (у VS Code и JetBrains — автоматически, с подсветкой текущего
    параметра). Нужно: автопоказ при входе в скобки, подсветка параметра.
24. **Подсказка при наведении — на своей задержке.** `textDocument/hover` есть в `lsp.ts`
    и `lsp-features.ts`; нет настройки задержки и «держать Ctrl — показать сразу» (VS Code).
25. **Свои подсказки поверх серверных.** `ui/tooltip.ts` обслуживает подсказки агента;
    перекрытия подсказок редактора своим словарём (слова проекта, сокращения) нет.
26. **Код-экшены по подсветке.** `codeAction` есть, но нет панели «быстрые исправления для
    этой диагностики» списком с описанием последствий (JetBrains Intention Actions).
27. **Инлайн-хинты настраиваются.** `lsp-inlay-hints.ts` есть; нет переключателя
    «типы / параметры / возвращаемые» через статусбар.
28. **Семантическая подсветка — поверх грамматики, а не вместо.** `semanticTokens` подключены;
    нужен слой приоритетов и откат на грамматику, когда сервер молчит (иначе файл «сереет»).
29. **Проверка орфографии — по серверу проекта.** Есть свой словарь (`main/spell`); нет
    использования LSP-сервера орфографии, если проект его объявляет.
30. **Диагностики — по проекту, не по файлу.** `project-diagnostics.ts` есть; нет сводки
    «сколько ошибок во всём проекте и где» с переходом из сводки.

### Проверено и найдено готовым — не пункт

- 30 модулей LSP в `shared`: завершение, сигнатура, наведение, выделение, ссылки, символы,
  переименование, code actions, code lens, semantic tokens, inlay hints, цвета,
  форматирование, свёртка, иерархии вызовов и типов, linked editing, moniker, progress,
  trace, status.
- Серверы: поиск, установка, bundled, пресеты, настройки проекта, журнал и трассировка.
- Завершение: список с документацией, дополнение по префиксу, порядок, «принять» и «отклонить».
- Переименование с подготовкой (`prepareRename`), workspace edit, множественные правки файлов.
- Диагностики в gutter, в правой колонке, в панели проверок; инлайн-значения отладчика.
