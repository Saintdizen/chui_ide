# Что предстоит

Только открытые задачи. Сделанное живёт в README, тестах и в истории файла
(`git log --follow -p TASKS.md`).

- **`edit.arg` от `patches` без пути — ловить отпечатком, а не разбором.**
  Свежий `npm run census` (02.11): главный отказ `edit` — `{patches: [{oldText,
  newText}]}`, то есть адреса нет нигде (11 вызовов, 31 % отказов `edit`).
  Разбор такой вызов принять не может, и это правильно; чинить надо тем, чтобы
  отказ был читаемым: форма едет в `unknown`, раздел «other/exit/arg — формы
  без своей причины» в `scripts/call-census.ts`. Дальше — решать по тексту, а
  не наугад: если в форме видно, что модель имела в виду файл из контекста,
  добавлять подстановку; иначе оставить отказ. Тест — `tests/step-counts.test.ts`.

- **Замер перехвата шелл-чтений ещё не чистый.** Условие пункта: `edit` ниже
  10 % отказов после «адреса строками» (`parseEditItem`, `END_OF_LINE`) и
  `textForAnchor`/`unsavedBuffer`. На 02.11 `edit.arg` 31 %, `edit.other` 4 —
  почти всё это форма вызова, а не перехват, поэтому условие не проверено.
  Нужен прогон без вызовов из памяти, затем `npm run usage` по неделям.
  Не подтвердилось — откатить правки, а не объяснять их пользу.

- **`pip check` после установки пакетов в `python.createVenv`.**
  `python.createVenv` по умолчанию даёт чистое окружение (`clean: true`), но
  когда пакеты всё же ставятся (пресет + requirements), конфликт версий pip не
  считает ошибкой — только `pip check` его называет. Место —
  `src/main/python/environments.ts`.

- **Заглушки в процессе вместо POSIX-скриптов — тогда порог покрытия вернётся
  на Windows/macOS.** Заглушки git/rg/lsp — шёлловые скрипты
  (`stubSupported = process.platform !== 'win32'` в `tests/*.ts`,
  `tests/ripgrep-stub.ts`), на Windows часть тестов снимается и прогон даёт
  ~80.75/75.06/78.63/83.54 при порогах 81/75/78/84. Лекарство — то, что уже
  сделано у `pip`: `vi.mock` вместо внешнего процесса.
