- [x] 107. `scripts/tools-probe.cjs` больше не врёт о зелёном (коммит
  `bfdff785`). Было два дефекта, и оба нашлись только запуском:
  (1) текст читался из `result.text`, а `runTool` кладёт причину в
  `summary` — поэтому любой отказ печатался пустым, «ОТКАЗ:» без
  причины; (2) причины отказа отсеивались регэкспом с широкими
  ветками (`нечего`, `недоступ`, `нет$`), которые глотали настоящие
  баги: «Путь недоступен: вне рабочей папки», «rg упал с кодом 2»
  считались нормой. Теперь причины — дословный список текстов из
  ответов, а непризнанный отказ идёт в stderr с `exit 1`.
  Прогон: 78 вызовов, 77 с признанным исходом, 1 честно непроверен
  (`web` — нужен интернет), неожиданных отказов ноль.

  Важное уточнение к разведке: 60 «нет окружения» — это не дыры, а
  инструменты, которым нужен Electron. Отказ у них внятный и
