# Что предстоит

Только открытые задачи. Сделанное живёт в README, тестах и в истории файла
(`git log --follow -p TASKS.md`).

Правило по этому файлу: пункт попадает сюда либо с воспроизведением, либо со
ссылкой на строку кода, либо с пометкой «проверить». Выдуманных дефектов здесь
быть не должно.

Урок из прошлых редакций: метод протокола ищется по всему `src`, а не в одном
файле транспорта — клиентская половина живёт в `lsp-features.ts`.

## Ловушка окружения (не забывать)

`web` (поиск) отвечает 404, `fetch` на `code.visualstudio.com` — «нет связи».
Документация читается через `terminal`: `curl -sSL <url>.md` (HTML — SPA, отдаёт
только шапку). Спецификация LSP — `metaModel.json`, полный:

```
curl -sSL https://microsoft.github.io/language-server-protocol/specifications/lsp/3.17/metaModel/metaModel.json
```

`.../specification.md` отдаёт **обрезанный** файл (42 КБ вместо полного) — по нему
список методов составлять нельзя. Сверку делать по metaModel, разбором JSON:

```python
c2s=[r['method'] for r in m['requests'] if r.get('messageDirection')=='clientToServer']
```

### Запросы: не хватает 6

1. **`textDocument/semanticTokens/range`** — подсветка видимого куска вместо всего
   файла; на больших файлах заметно.
2. **`textDocument/semanticTokens/full/delta`** — правка на символ перекрашивает
   весь файл.
3. **`textDocument/willSaveWaitUntil`** — форматирование перед сохранением
    (`editor.formatOnSave`). Одного `willSave` для этого мало.
4. **`resolve` у codeAction / codeLens / documentLink / inlayHint.** Сейчас
    `resolve` есть только у `completionItem` и `workspaceSymbol`; остальные
    приходят «как пришли» и теряют заголовки и команды. Звать, если сервер объявил
    `resolveProvider`.
5. **Pull-диагностика** (`textDocument/diagnostic`, `workspace/diagnostic`).
    Работаем на push-модели и так её и объявляем — честно, но на больших проектах
    push дороже. Отдельная задача: кэш, `resultId`, отмена.
6. **`didSave` для не открытых в редакторе файлов:** сохранение через файловый
    менеджер тоже стоит сообщать серверу.

## Часть 2. IDE

1. **Нет `Ctrl+Tab` по порядку использования.** VS Code держит MRU-список
   редакторов отдельно от порядка вкладок; нужно то же, и переживающее перезапуск.
2. **Состояние окна не восстанавливается точно.** Раскладка панелей пишется, а
   скролл, курсор и свёрнутые папки — нет: после перезапуска файл на первой строке.
3. **Множественный выбор в дереве не переживает перерисовку.** Выделение в
   `explorer.ts` есть, но любое обновление дерева (сохранение, git-статус) сбрасывает
   его на один файл.
4. **Нет блока «открытые редакторы» над деревом.** VS Code показывает его первым,
   и там же видны несохранённые.
5. **Настройки не показывают неправильные значения:** поле с мусором рисуется
   пустым вместо «ожидалось число».
6. **Нет файловых ассоциаций** (`files.associations`): расширение без языка
   остаётся без подсветки, хотя сервер для языка может быть.

## Часть 3. Проводник

1. **Нет «показать в проводнике»** (`Reveal in File Explorer`) из вкладки и
   редактора, хотя обратное действие есть.
2. **Перетаскивание не описано правилом.** Перенос в папку должен спрашивать при
   несохранённых правках и переносить файл вместе с историей.
3. **Нет сравнения двух файлов из дерева.** `diff-view` и `folder-compare-modal`
   есть, но зовутся только из SCM.
4. **Цепочки папок без файлов** (`a/b/c`) не сворачиваются в одну строку — там, где
   экономится половина высоты дерева.
5. **Проверить:** создание и переименование с недопустимыми именами (`a:b`, `/`,
   пустое) и отклик на больших каталогах (`node_modules`) — не воспроизводил.

## Часть 4. Редактор

1. **Нет раскраски скобок по уровням** (настройки `colorizeBrackets` нет;
   `rulers` при этом есть).
2. **Нет команд на несколько курсоров из VS Code:** `Ctrl+D` (следующее
   вхождение), `Ctrl+Shift+L` (все вхождения), `Ctrl+U` (откатить курсор).
   `addCursorAbove/Below` есть (`editor-commands.ts:464`), вхождения под курсором
   тоже уже находятся — для подсветки (`editor-view.ts:480`); остаётся отдать их
   командам.
3. **Контекстное меню не зависит от места:** в строке `import` и в обычной строке
   одно и то же меню; нет `Go to Definition` / `Peek` / `Rename Symbol` для слова
   под курсором.
4. **Нет переключения комментария блоком** (`Shift+Alt+A`) — только построчно.
5. **Нет превью ошибки при переходе `F8`:** курсор прыгает без контекста в
   статус-баре.
6. **Проверить:** поведение сворачивания пар скобок на многострочных литералах и
   шаблонных строках. Вчерашняя формулировка про `conceal` была догадкой — код не
   читал.

## Часть 5. Чат

1. **Сжатие посреди прогона режет по «ходу», а не по парам
   `assistant(tool_calls) → tool`** (`MIDRUN_KEEP_TURNS` в `service.ts`). Разрез,
   попадающий между ними, ломает протокол у строгих провайдеров (Anthropic). Резать
   только в точках, где нет висящих `tool_calls`.
2. **Нет `#`-упоминаний.** VS Code даёт `#file`, `#selection`, `#problems`,
   `#codebase`, `#web`. У нас есть приложение файлов, но не `#problems` (ошибки
   проекта в контекст) и не `#web`.
3. **Контекст не виден списком:** сколько токенов заняло что — нужно перед
   отправкой (как «Context» в VS Code).
4. **Ответ не делает кликабельными пути к файлам** и номера строк.
5. **Нет истории планов по беседе:** что уже сделано и когда.
