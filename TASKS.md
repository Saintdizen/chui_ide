       `.vitest-cache` весят 48 КБ и переписываются каждый прогон (холодный старт

       понадобится ещё: тест уведомлений ждёт события файловой системы (399 мс),
       подмодуль стоит 68 мс на `submodule add`.

- [ ] **`npm run check` на всех трёх ОС.** Решено 24.10: на mac/win тесты без
       покрытия (`npm test`), пороги проверяет только задача check. Остаток, по

       по себе — 114с без покрытия. Если понадобится ещё — смотреть, какие файлы
       на Windows держат эти секунды (`--reporter=json`).

       Выигрыша в скорости не будет — только в читаемости. Затевать, когда есть
       повод (править bisect или forge), а не «ради размера»: `src/shared/api.ts`
