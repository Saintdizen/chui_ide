## Правила

1. Перед пунктом — сверка с кодом.
2. Код и удаление пункта — один коммит.
3. Готовое удаляется сразу, без пометок.
4. Экономия без числа до и после не считается сделанной.
5. Пункт, оказавшийся готовым при сверке, удаляется тем же коммитом.

## Оптимизация UI: прокрутка тяжёлых файлов

Жалоба: на больших файлах прокрутка в редакторе идёт рывками.

Замер (11.11, п.81): `scripts/editor-scroll-bench.cjs` — настоящее окно, файл из
50k/200k строк, шаг 48 px за кадр, 90 кадров. Числа — медиана / p90 / худший кадр:
50k строк без миникарты 9.3 / 12.6 / 19.0 мс; 50k с миникартой 9.9 / 13.4 / 17.7;
200k строк 8.4 / 9.7 / 12.2 (это уже потолок 120 Гц — кадр чаще просто не
наступает). Вывод: программной прокруткой рывки НЕ воспроизводятся даже на
200k строк; единственная найденная цена — миникарта (~1.4 мс на кадр).
